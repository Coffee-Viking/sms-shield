## Description

SMS Shield is an Android SMS app focused on local, on-device message filtering.

It can be used as the default SMS app and supports keyword, number, wildcard,
and country-based block and allow rules, including Unicode message text.
Blocked messages are suppressed from regular notifications and kept in a
separate blocked folder.

The app also includes archive controls, skip-archive flags, conversation
grouping, OTP copy support, local import/export, dual-SIM send options, and
light/dark/OLED themes.

## Privacy / Network / Tracking

SMS Shield does not use advertising SDKs, analytics SDKs, Firebase, Google Play
Services, cloud spam detection, external AI services, or a network backend.

Filtering runs locally on-device.

## Sensitive Permissions

The app requests SMS/contact/SIM-related permissions because it is intended to
be used as a default SMS app:

- `RECEIVE_SMS`
- `READ_SMS`
- `SEND_SMS`
- `READ_CONTACTS`
- `READ_PHONE_STATE`
- `POST_NOTIFICATIONS`
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`
